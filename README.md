# MATLAB Electric

MATLAB R2024a / Simscape Electrical models and validation for buck converters, single-phase inverters, and a single-phase-input, three-phase-output AC-AC converter.

The AC-AC converter's [final design report](docs/acac_final_design_report.md) documents the original Requirements 1–7. The [robustness report](docs/acac_robustness_final_report.md) records the extended load and input-voltage study, including six combined corner cases and the limits found at light load and low line.

The retained AC-AC model is [models/acac_robust_optimized_r2024a.slx](models/acac_robust_optimized_r2024a.slx). Run `scripts/run_acac_robustness_validation.m` for fixed-design switching validation, or `scripts/run_acac_robustness_optimization.m` to reproduce a single screened candidate. Both require MATLAB R2024a with Simscape Electrical and the project folders on the MATLAB path.

`results/` contains compact JSON metrics and figures. Full switching waveform `.mat` files, Simulink build caches, and SDI archives are local generated artifacts; they are excluded from Git and can be regenerated by the validation scripts.
