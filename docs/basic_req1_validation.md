# Basic-1：三相 50 Hz 额定输出验证

## 设计与试验条件

- 独立模型：`models/converter1_basic_test_r2024a.slx`。
- 60 V 直流源是根据 32 V RMS 线电压选择的**设计假设**，不是题目给定值。理想正弦 PWM 所需调制指数为 0.8709296863，保留约 12.9% 的线性区间裕量。
- 六个真实 MOSFET 构成两电平三相 VSI，12.6 kHz SPWM，1 μs 开通死区；每相 1 mH/25.33 μF LC 滤波、1 Ω 电容串联阻尼；负载为浮置星形三相电阻，每相 `32/(sqrt(3)*2) = 9.237604307034 Ω`。
- 控制器使用模型工作区的 `Fout_Hz=50`；幅值反馈时间常数按 `1/Fout_Hz` 自适应。
- MATLAB R2024a Simscape Electrical 物理开关模型运行 1 s，测量稳态区间 0.8–1.0 s；采样重建率 200 kHz。
