# Basic-4：20–100 Hz、1 Hz 步长物理开关仿真

沿用通过 Basic-1/2/3 的独立三相 VSI 模型、60 V 设计直流源、额定浮置星形电阻负载和 32 V RMS 线电压目标。唯一改变的控制参数是模型工作区 `Fout_Hz`；每个整数频率 `20:100` 都单独运行了 MATLAB R2024a Simscape Electrical 六开关仿真，读取真实线电压、电流、调制量，再测量频率和 RMS。

81 点均执行；20、30、40、50、60、70、80、90、100 Hz 分别进行了完整 1 s 独立仿真，其余点运行到 0.7 s。所有测量窗从 0.4 s 以后开始，并由该点实际指令频率选取整数个周期。中断后通过逐点进度文件校验并续跑，未把未完成点计入通过结果。长时间扫描曾使默认 `/tmp` SDI 仓库占满，脚本已将临时记录移至用户缓存目录，并只删除本轮创建的 SDI run；`ToWorkspace` 测试点和 JSON 测量值保留。
